# Ideas para la próxima UI

Documento vivo para capturar ideas, preguntas y decisiones sobre la futura interfaz de Nox.

> La prueba de concepto nos enseñó cómo debe funcionar el sistema. La próxima UI debe explorar cómo queremos que se sienta.

## Dirección general

- Cálida, expresiva y enfocada en la conversación.
- Menos «panel táctico militar» y menos dashboard corporativo.
- Clara sin sentirse rígida o estéril.
- Capaz de mostrar operaciones complejas sin convertir cada detalle en ruido visual.
- Útil tanto durante una conversación rápida como durante una investigación larga.
- Un fondo de ascii que se mueve organico
- Modo claro/oscuro

- Desde el inicio debe ser pensada con modulos reutilizables y archivos mantenibles nada enorme
