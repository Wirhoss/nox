## Notices worth stating explicitly

### libvips, via `sharp` — LGPL-3.0

`sharp` is Apache-2.0, but it bundles prebuilt **libvips** binaries, which are
licensed under the **LGPL-3.0**.

Nox uses libvips as a dynamically loaded library through `sharp` and does not
modify or statically link it, so the LGPL's reciprocal obligations do not extend
to Nox's own source. Anyone redistributing Nox as a binary should keep libvips
replaceable and preserve its license notices, which ship inside the `sharp`
package.

libvips source: <https://github.com/libvips/libvips>

### Model weights are not covered by this license

The local provider and the semantic memory download model weights at runtime.
Those weights carry **their own licenses**, granted by whoever published them —
not by this repository and not by the Apache-2.0 license of
`@huggingface/transformers`.

The embedding model referenced in the documentation, `all-MiniLM-L6-v2`, is
Apache-2.0. Any other model you configure is yours to check.

### Browsers, via `playwright`

`playwright` is Apache-2.0, but the browser binaries it downloads are separate
software under their own licenses (Chromium: BSD-3-Clause and others; Firefox:
MPL-2.0; WebKit: LGPL and BSD).

### Services reached over the network

The `web` tool set calls **SearXNG** (AGPL-3.0) and **Crawl4AI** (Apache-2.0) as
external HTTP services. Neither is bundled, linked, or redistributed here, so
their licenses place no obligation on Nox. Operators run their own instances.
