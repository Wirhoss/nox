## CodeGraph

This repository has a CodeGraph index in `.codegraph/`. Use CodeGraph before
grep/find or manually reading files when locating or understanding code.

The CodeGraph CLI is installed at `/home/user/.local/bin/codegraph`. Bash-based
agent sessions may not include `/home/user/.local/bin` in `PATH`, so invoke that
absolute path (or run it through `fish -lc`) if `codegraph` is not found.
